
# 🧾 Billing System

A simple and user-friendly Billing System developed using **HTML, CSS, and JavaScript**. This application dynamically fetches product details and prices from a JSON file, calculates the total bill based on selected products and quantities, and allows users to print the generated bill.

## 🚀 Features

- **Dynamic Product Data:** Fetches product details and prices from a JSON file.
- **Automatic Price Calculation:** Calculates the total price based on product prices and quantities.
- **Real-Time Billing:** Automatically updates the bill when product quantities change.
- **Bill Generation:** Generates a well-structured and clear billing invoice.
- **Print Bill:** Allows users to print the generated bill directly.
- **Simple User Interface:** Easy-to-use and clean interface.
- - **Add Item:** User can add Item and update Price.

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the application.
- **CSS3** – For styling and designing the user interface.
- **JavaScript** – For dynamic functionality and price calculations.
- **JSON** – For storing product information and pricing data.

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Sarvar8950/billing-system.git
   ```

2. Navigate to the project folder:

   ```bash
   cd billing-system
   ```

3. Open the project in VS Code.

4. Run the project using the **Live Server** extension or you can directly run HTML file in browser.

5. Open the application in your browser and start generating bills.

> **Note:** Run the project using Live Server or another local HTTP server so that JavaScript can fetch data from the JSON file correctly.

## 💡 How It Works

1. Product details and prices are stored in the `price.json` file.
2. JavaScript fetches the product data from the JSON file.
3. Products and their prices are displayed dynamically on the webpage.
4. The system calculates the bill based on the selected products and quantities.
5. The generated bill can be printed directly using the browser's print functionality.
